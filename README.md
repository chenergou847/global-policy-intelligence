# 全球政策与监管情报分析

面向**企业管理层、公共事务、法务和财务团队**的全球政策与监管情报分析技能。

样例参考：https://github.com/demo-global-policy-intelligence

## 能力概览

用于分析国家、地区、省州、市县区层面的：

- 政策方向
- 法律法规
- 监管与执法趋势
- 地方实施情况
- 行业舆情

并解释政策背后的**宏观与治理动因**，及其对**具体公司**的影响。

## 输出内容

| 输出项 | 说明 |
| --- | --- |
| 总体判断 | 利好 / 利空 |
| 合规风险 | 按 P0–P3 分级 |
| 政策机会 | 可争取的政策窗口 |
| 行动责任 | 明确到责任方 |
| 未来关注点 | 需持续跟踪的信号 |

## 内置专题分析框架

针对国际政治经济议题设有专门框架：

- 地缘政治
- 国别政治生态
- 科技竞争与供应链重构
- 制裁与出口管制
