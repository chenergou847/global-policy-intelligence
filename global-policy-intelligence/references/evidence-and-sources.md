# 证据、来源与引用规范

本文件规定来源如何定性、快照如何记录及主张如何引用。抓取回落、信源配置和故障诊断按需读 [retrieval-pipeline.md](retrieval-pipeline.md)；逐项校验契约读 [claims-ledger.md](claims-ledger.md)。

## 一、分开记录五个维度

| 维度 | 含义 | 不可混同 |
|---|---|---|
| 来源属性 | `[U]` 用户陈述、`[I]` 授权内部资料、`[P]` 公开来源 | 内部资料不自动证明法律要求，用户陈述不等于独立核验 |
| 权威等级 `layer` | L1–L5，针对来源角色判定 | L1 可以抓取失败，L3 可以取得完整正文 |
| 获取状态 `fetch_status` | full / partial / listing_only / scanned_pdf / blocked | 只描述拿到了什么，不决定发布者权威性或法律效力 |
| 法律/政策状态 | 生效、待生效、草案、倡议、执法信号等 | 官方发布的草案也不是现行义务 |
| 主张支持关系 | 某段材料是否支持某条主张及其置信度 | 文件真实、正文完整不等于解释或因果成立 |

对用户或内部输入，权威等级可记“不适用”；保留授权来源及内部定位，不伪造公开 URL。

## 二、公开来源等级

| 等级 | 来源 | 用法 |
|---|---|---|
| L1 原始权威 | 法规原文、政府公报、监管公告、法院判决、官方统计、交易所/监管申报 | 核心法律事实、状态和适用条件的首选 |
| L2 官方解释 | 实施指南、政府问答、官方发布会、官媒权威解释、国际组织正式文件 | 解释目的、执行口径和宏观背景；不能替代法规原文证明义务或罚则 |
| L3 高可信二手 | 主流财经媒体、专业律所、行业协会、学术/研究机构 | 补充实务与行业反应，尽量回溯 L1/L2；不能单独支撑核心主张 |
| L4 一般线索 | 普通媒体、咨询文章、商业数据库摘要、专家评论 | 发现线索，不支撑核心判断 |
| L5 未核实 | 社交媒体、匿名消息、无原始出处的转载 | 不作为事实证据 |

等级取决于实际发布主体及材料用途，不凭域名、平台或页面长度自动赋级。国际组织报告或官方评论只有在其职权与材料内容范围内才有相应支持力。

### 禁止作为证据的来源

百家号、头条号、搜狐号、网易号、企鹅号等平台自媒体，微信公众号、知乎、微博及其他个人社交账号，自媒体社评、内容农场、无原始出处转载和匿名爆料，不进入证据台账或正文引用。看似官方或官媒入驻账号也回溯到机构官网、公报或政务原始发布页。

命中时只提取原始文件线索，回溯成功后引用原始来源，失败则弃用。不要把媒体机构自有官网的正式报道与开放平台账号混为一类。仅有社评时写明未取得权威依据，不用低质信息凑数。

## 三、获取状态与证据门槛

| 状态 | 判定 | 使用边界 |
|---|---|---|
| `full` | 已取得与所引文档对应的完整、可读正文，含相关条款及必要附件 | 结合 L1/L2、有效状态和具体支持关系，才可能支撑核心 fact / inference |
| `partial` | 正文截断、相关条款或附件缺失 | 只用已取得部分作有限的辅助说明，披露缺口；不得作为核心证据 |
| `listing_only` | 只有目录、标题、链接或搜索摘要 | 只作待核线索，不据此写政策事实、日期或门槛 |
| `scanned_pdf` | 取得图像页但无可用文字层，尚未完成 OCR/核对 | 不满足可读快照门槛，不直接支撑事实 |
| `blocked` | 页面无法取得、验证码、登录墙、付费墙或渲染失败 | 记录阻断原因与已试路径，不推测正文 |

扫描 PDF 是文件特征，不是权威等级。采集器可将无可用文字层的记录标为 `scanned_pdf`，该状态表示尚未取得可读正文；经 OCR/VLM 获取后人工核对关键条款、数字和完整性，再据实标为 full 或 partial，保留扫描/OCR 方法说明。

元数据缺失与正文完整性也分开：文件本无文号、无生效日期可记“无/不适用”，不因此降为 L3 或 partial。缺少判断必需的日期、状态或适用对象时，对应主张待确认，不凭空补齐。

核心 fact / inference 的门槛是**该项每个 evidence URL 均对应可读 full L1/L2 快照**；证据库别处有一份 full 文件不能替该项过关。L3/partial 等辅助背景另列 supporting 主张，不混入核心主张的 evidence。辅助事实也须在其所引材料中有真实依据。模型记忆用于提出检索方向，不能作为已核验政策事实的来源。

## 四、检索与核验

- 单政策先核对指定文件的版本、条款、权限、对象与有效状态；完整扫描围绕公司暴露建立法域与主题清单；更新核验变更及其依赖，不每次重做全部扫描。
- 优先官方法规库、公报、监管机构与发布机关官网；按需要使用官方术语、文号、简称、年份、当地语言和译名。取得足够证据后结束检索，不机械执行四轮或穷举查询矩阵。
- 扫描或更新需要判断近期变化时，检查相关官方动态与归档，记录实际覆盖范围。高影响、争议或易变事项尽量交叉核验；第二来源须独立，不把转载算作独立证据。
- 机器可读接口、文本、静态页面、PDF、渲染等按可用性选择；页面打开不等于取得正文。确认内容不是二进制、验证页、导航页或镜像工具栏。设置合理尝试预算，失败后留痕并换替代官方路径。
- 遇验证码、登录墙或付费墙停止，不绕过防护。保留未取得正文的来源、原因、已试地址及可行下一步，不静默省略。
- 核验引用对应的标题、发布者、文号（如有）、发布日期、生效日期（如适用）、条款、地域和政策状态。义务、门槛、罚则直接回查 L1；来源冲突说明权限、版本、时间与适用对象差异。
- 报告截止日后材料标为补充更新，不混入原截止时点判断；此前报告的结论不得作为独立证据自引。

### 未检索到的表述

使用：“截至 {时间}，在 {实际信源}、{时间/法域范围} 中，未检索到可由官方来源确认的相关动态；已试查询为 {查询词}，限制为 {未覆盖或阻断}。”

**未检索到不代表不存在**，也不能推出政策未出台、未执法、没有风险或公司不适用。若需断言“不存在某项要求”，应有直接支持该否定命题的适用规则或权威说明，空搜索结果不够。公司近期动态无结果也遵守同一边界。

## 五、来源台账与快照

来源台账给每个来源稳定编号 `S1` 等，记录实际情况；成功证据与待核/失败线索分开，不能把有记录称为已覆盖。以下是可复核记录的内容要求，不强制在正文铺开宽表，也不要求无关字段凑满固定数量。

| 记录组 | 内容 |
|---|---|
| 身份与用途 | source/source_key、来源属性、layer、发布主体、title、所支持的 claim ID |
| 文件状态 | docno（无则注明）、pub_date、effective_date（如适用）、policy_status、版本/地域/对象限制 |
| 获取情况 | fetch_status、fetch_method、访问/抓取时间、text_chars、attempts 与失败或缺口说明 |
| 存证 | 原始 URL、snapshot_id/内容哈希、可读正文快照位置、定位；首尾指纹可辅助诊断但不能证明全文完整 |

正文引用至少可追溯到 URL、访问/抓取时间、可读快照及内容哈希。文号有则记录，没有文号的正式问答或指南仍可引用，不编造文号。不要猜测未经访问的 URL。

逐字引用保留原句和条款/段落定位，不用改写冒充引文；长度以支持具体主张所需为准，不强制凑 40 字。译文说明翻译并保留原文供复核。核心事实中的引文、文号、金额、门槛和完整日期，只能在**该条 claim 的 evidence 所指材料**中核对；别处出现相同数字不构成支持。

内部资料只读取授权的必要片段，以内部定位供授权读者复核；不把合同、客户、收入、战略或未公开交易发送到公开搜索。公司输入与公开资料冲突时分别标明，不将内部说法包装为公开事实。

## 六、置信度、覆盖和校验

高置信度需要直接且适用的证据、清楚的有效状态及公司暴露；中置信度说明执行或传导的不确定环节；低置信度不能豁免核心证据门槛。方向、影响和置信度分开，证据不足时明确无法定向。

覆盖统计按 claims ledger 计算：`X 条核心 fact/inference 中，Y 条满足逐项 full L1/L2 可读快照门槛`，Y 要求该项 evidence 非空且每个 URL 都满足门槛；X=0 写“不适用”，不称为 100%。assumption/company 单独记，不加入该分母。正文可以一行交代；未取得正文与未覆盖范围按实际缺口列出，不生成空附录。此比例不证明法域覆盖全面或推理正确。

有采集工具时，严格校验带上 `--claims claims.json`；具体命令见 [claims-ledger.md](claims-ledger.md)。脚本只检查契约和局部证据匹配，**不能替代人工检查、不能证明可核验事实都正确，更不能验证因果**。工具不支持或未运行严格模式时说明实际核验方式与限制。
