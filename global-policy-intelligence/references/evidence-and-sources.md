# 证据、来源与引用规范

## 一、把四件事分开

不要用一个“可靠/不可靠”标签混合判断。每条重要信息分别记录：

1. 来源属性；
2. 来源权威等级；
3. 法律或政策状态；
4. 对该结论的支持强度。

## 二、来源属性

- `[U]`：用户在当前任务中的陈述；
- `[I]`：用户授权的知识库、内部附件或企业资料；
- `[P]`：公开网络资料。

来源属性不等于权威性。内部资料可以准确描述经营事实，但不能自动证明法律要求；用户陈述可作为分析输入，但未必经过独立核验。

## 三、论证类型

- `[F]` 明文事实：法规、公告、统计或可直接核验事实；
- `[A]` 分析推论：从一个或多个事实推导出的判断；
- `[S]` 情景假设：信息不足时明确设定的条件；
- `[Q]` 待确认：对结论重要但没有足够证据的信息。

组合使用，例如 `[P-F]`、`[I-F]`、`[P-A]`。不要把 `[A]` 写成监管机关已确认的 `[F]`。

## 四、公开来源权威等级

| 等级 | 来源 | 用法 |
|---|---|---|
| L1 原始权威 | 法律法规原文、政府公报、监管公告、法院判决、官方统计、交易所/监管申报 | 核心法律事实和状态的首选 |
| L2 官方解释 | 实施指南、政府问答、官方发布会、官媒权威解释、国际组织正式文件 | 解释目的、执行口径和宏观背景 |
| L3 高可信二手 | 主流财经媒体、专业律所、行业协会、学术/研究机构 | 补充行业反应和实务背景；尽量回溯 L1/L2 |
| L4 一般线索 | 普通媒体、咨询文章、商业数据库摘要、专家评论 | 发现线索，不单独支撑核心判断 |
| L5 未核实 | 社交媒体、匿名消息、无原始出处的转载 | 不作为事实，不进入来源台账；必要时仅在正文描述为待核实舆情 |

官媒适合解释政策语境，但不能替代法规原文证明义务、罚则、门槛或生效日期。

### 禁止来源（不得进入来源台账与正文引用）

以下自媒体与社评类内容一律禁用，无论其内容看起来多么专业、被转载多少次：

- **平台自媒体频道**：百家号（baijiahao.baidu.com）、头条号（toutiao.com）、搜狐号、网易号、企鹅号/趣头条等内容开放平台文章；
- **自媒体与个人账号**：微信公众号、知乎、微博、哔哩哔哩、抖音、小红书等社交平台上自行发布的内容；
- **内容农场与聚合转载**：无原始出处的转载稿、营销号稿件、清单体与标题党内容；
- **匿名消息**：匿名爆料、无法溯源的聊天记录与群组消息。

处理规则：

1. 检索命中禁止平台链接时，只作为线索使用：提取其中提到的法规名称、文号、发布机关和日期，回溯 L1/L2 原文。回溯成功则引用原始来源；回溯失败则弃用，不得写入来源台账，也不得在正文中作为依据引用。
2. 即使账号看似官方机构或官媒入驻账号，也不直接引用平台链接，一律回溯到机构官网、公报或政务发布页的原始出处。
3. 识别特征：URL 域名在上述清单内；署名"本文由自媒体号××发布"或类似声明；全文无原始出处；标题情绪化、结论先行。符合任一特征即按禁止来源处理。
4. 某议题仅有社评内容、无权威来源时，如实写"未检索到可由权威来源确认的动态"，不得用社评凑数或降低标准引用。

## 五、法律与政策状态

每项规则标记为：

- 已生效；
- 已公布、待生效；
- 草案/征求意见；
- 政策倡议/指导意见；
- 执法案例/监管信号；
- 行业观点/舆情。

草案不得写成现行义务；单次执法案例不得直接写成普遍规则；地方实施不得扩大为全国要求。

## 六、结论置信度

- **高**：有 L1 直接证据，关键日期、对象和状态已确认，公司适用事实也较清楚；
- **中**：有 L1/L2 支撑，但地方执行、细则或公司暴露仍有不确定性；
- **低**：主要依赖二手来源、早期政策信号或公司信息明显不足。

置信度与利好利空方向分开。一项事项可以是“高置信度利空”或“低置信度潜在利好”。

## 七、检索与交叉核验

### 检索质量纪律

1. **官方渠道优先**：境内法规政策优先检索国家法律法规数据库（flk.npc.gov.cn）、中国政府网（www.gov.cn）、发布机关官网和地方政府门户；境外优先检索官方公报（如美国 Federal Register、欧盟 EUR-Lex、英国 legislation.gov.uk）、监管机构官网（如 BIS、OFAC、各国数据保护机构）和国际组织官网（WTO、OECD、UN）。
2. **多轮检索**：第一轮按法规全称、简称和文号找原文；第二轮按发布机关与主题词找官方解读、发布会和执法动态；第三轮用律所客户提示、行业协会和主流财经媒体补充实务背景；第四轮对关键事实交叉核验。一轮检索词无结果时，换官方术语、简称、文号、当地语言名称或英文译名再试；不得以单轮检索失败得出“无动态”结论。
3. **检索词纪律**：使用关键词与文号、机关名、年份的组合，避免整句自然语言检索；用时间范围限定到回看区间；不得把公司内部信息、内部资料内容或敏感经营数据作为检索词。
4. **先分流后打开**：对搜索结果先按来源类型分流（原始权威 / 官方解释 / 高可信二手 / 一般线索 / 自媒体社评），再决定是否打开；命中禁止来源时按第四节"禁止来源"规则回溯或弃用，不因排名靠前而采信。

### 交叉核验

1. 先找原始法规或正式文件，再找解释和行业反应。
2. 对支撑核心结论的每个 L1/L2 来源，用网页读取工具实际打开原文，核对标题、发布机关、文号、发布日期、生效日期、适用对象、地域和有效状态；只有实际打开核验过的链接才可写入来源台账。
3. 重要数字、期限、门槛和罚则直接核对原文条款。
4. 高影响事项尽量以两个独立来源核验，其中至少一个为 L1；只有一个 L1 时说明单一来源状态。
5. 来源冲突时并列展示差异，解释权限、时间或适用对象，不静默选择更符合预设结论的一方。
6. 链接打不开、原文未找到或只能看到二手转述时降低置信度并明确说明。
7. 截止日后发生的信息不得混入报告；如必须补充，标明“截止日后更新”。

## 八、内部资料保护

- 仅在用户授权范围内检索并读取必要片段。
- 不把内部合同、客户、收入、战略、未公开交易或其他敏感信息发送到公开搜索。
- 公开检索使用一般化主题词和已公开公司信息。
- 内部资料与公开资料冲突时分别标记，不把内部说法包装为公开事实。
- 报告中的内部定位应足够让授权读者复核，但避免不必要复制敏感全文。

## 九、来源台账

为正文使用简短编号 `S1`、`S2`……，在附录记录：

| 字段 | 要求 |
|---|---|
| 编号 | 唯一编号 |
| 来源属性 | U / I / P |
| 权威等级 | L1–L5；U/I 可注明“不适用” |
| 发布机构 | 原始发布主体 |
| 标题 | 原始标题，不杜撰译名 |
| 文号 | 有则记录，无则写“无/未标明” |
| 发布日期 | 原文日期 |
| 生效日期 | 如适用 |
| 访问日期 | 实际访问日 |
| 状态 | 生效、待生效、草案等 |
| 链接/内部定位 | 真实 URL 或内部文件定位 |
| 支撑内容 | 具体支持哪一项结论 |
| 限制 | 地域、对象、证据缺口 |

不要生成看似真实但未经访问的链接。链接无法确认时，保留来源标题和检索状态，明确“未取得可核验原文链接”。

写入台账前逐条核对链接域名与发布主体：百家号等禁止来源清单内的平台链接一律不得出现；发现已误入的，删除该条并将依赖它的结论降级为待确认或另行回溯原始来源。
