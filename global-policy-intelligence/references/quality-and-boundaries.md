# 质量、边界与交付检查

## 一、事实与来源

- [ ] 每个关键法规、政策、日期、数字和公司动态都能追溯到真实来源。
- [ ] 重要法律结论优先引用 L1；官媒或二手解读没有替代法规原文。
- [ ] 链接已实际取得，不是根据标题或 URL 规律猜测。
- [ ] 已区分用户陈述、内部资料、公开资料，以及事实、推论、假设、待确认。
- [ ] 已标记生效、待生效、草案、倡议、执法信号和行业观点。
- [ ] 官方渠道无近期动态时已如实说明，没有用社评凑数。
- [ ] 来源台账与正文引用中没有百家号、头条号、搜狐号、网易号、微信自媒体公众号、知乎、微博等禁止平台链接；检索命中的自媒体内容已回溯原始来源或弃用。
- [ ] 已执行多轮检索（法规全称、简称、文号、机关名、当地语言名称），没有以单轮检索失败得出“无动态”结论。
- [ ] 报告中的结论没有超过证据可以支持的强度。

发现无法核实的关键事实时，删除、缩小结论，或改为待确认；不要用模糊措辞掩盖来源缺口。

## 二、公司相关性

- [ ] 已询问或复用了公司的业务、地域、主体、暴露、目标和时间尺度。
- [ ] 重点法域按真实业务暴露选择，而非全球政策罗列。
- [ ] 每个核心事项都说明为什么与该公司有关。
- [ ] 没有虚构收入、成本、市场份额、牌照、门店、供应商、客户或数据流。
- [ ] 信息不足时明确使用初步扫描、假设和待确认项。
- [ ] 已核验与政策暴露相关的近期公司动态；无结果时如实说明。

## 三、分析而非汇总

- [ ] 已解释政府为什么在当前时点采取该政策导向。
- [ ] 已区分官方目的和分析推论，并说明推论依据。
- [ ] 已解释行政层级、权限和上下传导。
- [ ] 已从政策走到行业，再走到公司主体、业务、资金和时间影响。
- [ ] 已包含条件、例外、反向信号和失效点。
- [ ] 行业舆情只作为执行、商业或声誉信号，没有替代法律事实。
- [ ] 高影响判断已做关键假设检验，给出竞争解释与判别指标，没有默认采纳单一解读。
- [ ] 地缘政治与科技竞争议题：政治表态与公布文件、执法事实分离；智库和媒体预测未写成既定事实；未来走向设有可观察指标，且置信度未超过证据允许的上限。

## 四、管理决策与行动

- [ ] 首页明确给出利好、利空、中性偏利好或中性偏利空。
- [ ] 同时给出影响程度和结论置信度。
- [ ] 优先级与紧迫度矩阵使用规定分级（即时决策 / 窗口内准备 / 跟踪观察），紧迫度反映决策窗口与不可逆性，未出现红黄绿等颜色标签。
- [ ] 低概率高影响的尾部风险没有被“概率低”了结，配有触发指标、预案和对冲动作。
- [ ] 合规风险和政策机会分开列账并分别排序。
- [ ] P0–P3 符合紧迫性、不可逆性、影响和窗口定义。
- [ ] P0 已解释为何不能等；P3 有触发器和复查日。
- [ ] 每项行动有动作、责任角色、时限、依赖和验收标准。
- [ ] 管理层、公共事务、法务、财务都能找到与自己相关的决策或动作。
- [ ] 未来关注点说明何种信号会改变当前判断。

## 五、时效与地域

- [ ] 报告写明绝对截止日、回看期、前瞻期和访问日期。
- [ ] 默认近 3 个月与未来 6 个月得到正确应用；超期重大事项已说明纳入原因。
- [ ] 跨国区域、国家、州省和市县区没有混写。
- [ ] 地方执行没有被扩大为全国规则，中央倡议也未被误写成地方已落实。
- [ ] 需要地方主管部门确认的口径已列为行动或待确认项。

## 六、敏感信息

- [ ] 仅使用用户授权的内部资料。
- [ ] 没有把内部合同、收入、客户、战略或未公开事项发送到公开搜索。
- [ ] 内部事实没有被写成公开事实。
- [ ] 报告只保留完成判断所必需的敏感细节。

## 七、专业边界

本报告用于政策情报和经营决策参考，不替代正式法律、税务、会计或投资意见。涉及以下事项时，明确建议专业机构确认：

- 许可、处罚、诉讼、调查或监管问询；
- 交易架构、税务处理、会计确认和跨境资金；
- 数据跨境、制裁、出口管制和国家安全审查；
- 地方窗口指导、未公开口径或重大申报承诺。

不要用免责声明掩盖本应完成的检索；免责声明只说明专业责任边界。

## 八、输出边界

- 默认生成 Markdown，不直接生成 Word、PPT 或图表。
- Word 排版由当前环境可用的 Word 转换技能（如 `docx`）完成；可视化和演示文稿由对应技能完成。
- 用户样例仅用于学习结构和表述侧重，不继承其中公司、行业、地域、政策数字、引用编号或结论。
- “全球”表示能力范围，不表示每份报告穷尽所有法域；主动声明未覆盖部分。

## 九、最后一道红线

出现以下任一情况，不把报告描述为已完成的高置信度公司分析：

- 关键法规原文或法律状态无法确认；
- 公司适用主体或核心暴露未知；
- 重大判断只由 L4/L5 来源支撑；
- 来源台账中出现百家号等禁止平台链接；
- 来源冲突尚未解释；
- 存在可能虚构的链接、日期、数字或引语。

此时缩小范围、降低置信度、明确缺口并给出下一步核验动作。宁缺毋滥。
