# 地缘政治、国别政治生态与科技竞争分析

当政策议题处于大国竞争、经济治国术（economic statecraft）与技术对抗背景下时，通用监管分析不足以解释动因与预判走向。本文件提供国际政治经济议题的专门框架，并对此类议题执行更高的分析标准。

## 一、何时使用

事项涉及以下任一情形时使用本框架；一般性本地监管议题仍用 `policy-analysis-framework.md` 即可：

- 地缘冲突、大国竞争、联盟与阵营变化影响市场准入、供应链或资金流动；
- 制裁、出口管制、投资安全审查、关税等经济治国工具已经或可能针对公司业务；
- 科技竞争与供应链重构：半导体、人工智能、量子、生物科技、关键矿产等受争夺领域；
- 选举、政权更替或国别政治生态重大变化带来政策不确定性；
- 公司母国、行业或产品在目标市场政治话语中已被“安全化”或政治化。

使用本框架不降低证据要求，反而提高：制裁名单、管制条例、审查决定必须回溯官方原文（L1）；智库报告、媒体分析和专家预测只作线索与竞争假设素材，不得写成既定事实。

## 二、国别政治生态六维分析

按决策问题选取相关维度，不机械全列：

| 维度 | 分析要点 | 对政策的影响 |
|---|---|---|
| 权力结构 | 宪制安排与实际权力分布；对外经济政策由谁拍板（元首、内阁、议会、安全机构、地方政府）；否决点在哪 | 决定政策形式（立法/行政令/部门规章）与可逆性 |
| 政治周期 | 选举、议会会期、预算周期时间表；选举前后哪些政策被加速或搁置 | 决定政策窗口与出台节奏 |
| 利益结构 | 受益与受损产业、资本集团、工会、军工、能源与农业利益；游说与政治献金渠道 | 决定政策推力强度与可持续性 |
| 官僚政治 | 牵头机构与部门间分工竞争；部际分歧；关键人事变动 | 决定执行裁量与执法力度 |
| 意识形态与舆情 | 民族主义、民粹主义、经济主权论述；对公司母国的态度；媒体生态；目标行业是否已被政治化 | 决定政策的政治成本与企业被殃及风险 |
| 对外结盟 | 同盟与条约义务；对大国依赖与对冲策略；多边机制参与；受域外管辖的暴露 | 决定政策是内生还是外压驱动，以及跨国协同空间 |

输出要求：说明政治生态如何影响政策的**概率、速度和形式**；区分结构性慢变量（权力结构、利益结构）与事件性快变量（表态、个案、舆情事件）；不把个别领导人言论直接当作政策预测。

## 三、经济治国工具识别

判断哪些工具已经或可能作用于公司业务，并逐项分析法律机制：

| 工具 | 常见形式 | 对公司需核对的要点 |
|---|---|---|
| 制裁 | 名单制裁、行业制裁、次级制裁 | 列名标准与程序、交易对手合规义务、一般许可、除名空间 |
| 出口管制 | 两用物项清单、实体清单、最终用途管制、外国直接产品规则 | 受控技术/设备/软件的许可要求与审批周期、最低含量规则、供应替代、域外效力 |
| 投资审查 | 国家安全审查、关键科技/基础设施/数据领域投资限制 | 强制申报门槛、审查时限、既往案例口径、交易结构调整空间 |
| 贸易措施 | 关税、配额、反倾销/反补贴、保障措施 | 成本转嫁能力、原产地规则、排除程序 |
| 金融措施 | 支付通道限制、资产冻结、资本管制、融资禁令 | 资金路径、结算币种、利润汇回、债务契约条款 |
| 数据与数字主权 | 数据本地化、跨境传输限制、平台与算法监管 | 数据架构合规性、商业模式可行性、内容与算法责任 |
| 供应链政策 | 本地含量要求、回岸/友岸激励、关键物资储备 | 采购重构成本、认证周期、补贴资格与挤出效应 |

对每项工具写明：法律依据与主管机构、触发条件、历史执行强度、域外效力与法律冲突（如阻断法规）、公司现实应对选项与窗口。

## 四、科技竞争分析

1. **技术栈位置**：公司业务处于受争夺技术链条的哪一环；上游依赖（设备、材料、EDA 与软件、模型、算力、数据、人才）及其可控性与可替代性。
2. **卡点与替代方案**：哪些环节由哪些国家或企业掌握不可替代能力；替代方案成熟度与实现时点；切换成本与认证壁垒。
3. **产业政策与补贴**：主要经济体补贴规模与申领条件、本地化要求，对非本土企业的溢出或挤出效应。
4. **标准与规则竞争**：国际标准组织布局、专利池与许可、认证互认；标准分裂导致的市场割裂与重复合规成本。
5. **人才与科研合作**：签证与背景审查限制、跨境研发合作与出口管制边界、学术交流与数据合规。
6. **军民两用定义扩散**：“两用”技术定义收紧趋势及其对商用产品边界的影响。

## 五、地缘政治传导链

地缘分析的终点必须是公司暴露与应对窗口，不停留在“局势紧张”：

`地缘事件或结构变化 → 国家政策反应（工具、强度、节奏） → 行业与供应链传导（准入、成本、需求、合规义务） → 公司主体、业务、资金、数据、时间暴露 → 公司应对选项与窗口`

每一环写明证据与置信度。对跳跃环节（如由“双边关系恶化”直接推断“公司将被列名”），必须列出竞争解释与判别指标；证据不足时降低置信度并列入待确认项。

## 六、分析纪律

- **言论与行动分离**：官方表态、外交辞令、官媒评论不等于已经或必然出台的政策。以公布法律文件、执法记录、预算与人事行动判断方向；“言论—行动差距”本身作为分析对象和潜在先导指标记录。
- **竞争假设**：对高影响地缘判断给出至少两个有一定证据支持的假设（如“谈判筹码”与“长期结构性遏制”、“针对性执法”与“普遍性收紧”），说明各自的判别指标、最早可观察时点，以及每种假设成立时对公司的不同含义。
- **历史类比纪律**：援引先例（如某国对某行业的既往措施）时说明制度背景、相互依存结构与技术条件的异同；类比只用于生成假设，不作为证据。
- **信号监测**：为每项重要地缘判断设定可观察指标（立法进程、名单更新、执法案例、选举结果、官方口径变化），写入“未来重要关注点”表，注明最早可观察时间和触发后判断如何改变。
- **拒绝决定论与阴谋论**：不把“必然脱钩”“必然冲突”写成结论；不采信无法归因的隐秘决策叙事。
- **置信度上限**：对未来政治走向的判断默认不超过“中”置信度，除非有已公布法律文件、官方时间表或多次一致执法记录支持。

## 七、报告呈现

- 地缘政治、科技竞争专题在标准事项卡片基础上增加：**竞争解释**、**判别指标**、**域外效力与法律冲突**（如适用）。
- 在优先级与紧迫度矩阵中，此类专题的紧迫度反映决策窗口与不可逆性，而非事件热度：断供、列名、市场准入突然关闭等尾部风险即使紧迫度为“跟踪观察”，也必须配套触发指标、触发后预案和低成本对冲动作（如双源采购、安全库存、合同保护条款），不得以“概率低”了结。
- 政治背景只写解释动因和走向所必需的部分；报告始终落回公司决策问题，不写成国际时评。
