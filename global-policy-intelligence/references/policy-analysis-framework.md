# 政策分析框架

## 一、从政策动作走到公司影响

每个重点事项按同一条论证链展开：

1. **发生了什么**：新法、新规、执法、预算、试点、许可或官方表态；
2. **官方目的**：文件或主管部门公开说明的目标；
3. **深层动因**：由可靠事实支持的宏观、财政、产业、社会或治理因素；
4. **权限与层级**：谁制定、谁执行、谁有裁量权；
5. **传导机制**：通过准入、成本、需求、补贴、执法或舆情如何影响行业；
6. **公司暴露**：哪些主体、业务、资金和时间节点受影响；
7. **边界**：成立条件、例外、反向信号、失效点和待确认信息。

没有完成第 3、5、6 步的内容通常只是政策摘要，不应成为核心结论。

## 二、宏观与治理动因

按实际政策选择，不机械套用：

- 经济增长、就业、通胀、消费与财政压力；
- 产业升级、技术自主和补贴效率；
- 供应链韧性、本地化与关键基础设施；
- 数据、网络、国防或国家安全；
- 市场竞争、平台治理与消费者保护；
- 能源转型、环境和公共健康；
- 人口、住房、劳动力和社会保障；
- 地缘关系、贸易与投资安全；
- 地方招商、税基、城市更新与公共服务；
- 政府治理能力、执法资源和政治周期。

将动因分成：

- **官方明确说明**：可作为事实引用；
- **分析推论**：说明依据和替代解释；
- **无法证实的猜测**：删除或降为待验证假设。

“政府支持某产业”不自动等于公司受益；继续核对主体资格、业务范围、资金路径、申报条件和地方细则。

动因主要涉及地缘政治竞争、国别政治生态、制裁与出口管制或科技竞争与供应链重构时，读取 `references/geopolitics-and-tech-competition.md`，用其国别政治生态六维、经济治国工具识别与科技竞争框架深化，并执行其分析纪律。

## 三、行政层级

分别回答：

| 层级 | 需要分析的问题 |
|---|---|
| 跨国/区域组织 | 是否直接适用，还是由成员国转化/执行 |
| 国家/联邦 | 立法、产业政策、税务、贸易和国家级监管方向 |
| 州省/自治区 | 实施裁量、地方监管、财政支持和区域差异 |
| 市县区 | 许可、执法、招商、补贴、土地、门店和办事窗口 |

说明上下级政策如何传导、地方有哪些裁量、公司实际接触哪个主管部门。没有当地可靠材料时，不用上级宏观表态推定市县区已经实施。

## 四、监管态势

法规文本之外，再观察：

- 执法频次、处罚类型和典型案例；
- 监管问答、检查通知和专项行动；
- 许可、备案、申报和审查周期变化；
- 预算、人事、机构职责和监管资源；
- 法院判决、行政复议和争议焦点；
- 地方执行差异与窗口指导。

单一案例只能证明该案例存在。若要推断趋势，至少寻找时间序列、多个案例或主管部门明确表态。

## 五、行业舆情

行业舆情用于识别执行阻力、商业预期、声誉风险和潜在政策修正，不替代法律事实。优先行业协会、上市公司披露、权威研究和多方可验证观点。

对舆情写明：

- 谁在表达；
- 代表何种利益；
- 是否有数据或原始材料；
- 与政策文本一致、冲突还是补充；
- 对公司有什么现实传导。

匿名、单一观点或社交媒体热度不得支撑核心判断。

## 六、情景分析

至少考虑：

- **基准情景**：现行规则和最可能执行方式；
- **收紧情景**：细则严格、执法加码或门槛提高；
- **放宽/机会情景**：延期、豁免、试点扩围或补贴落地。

必要时增加：

- 不同主体或交易结构；
- 不同资金路径；
- 不同数据流或供应链；
- 不同城市/区县执行；
- 政策到期、续期或政权更替；
- 做与不做某项企业行动的反事实。

每个情景说明触发条件和最早可观察信号，不写泛泛的“存在不确定性”。

## 七、结构化分析纪律

分析的价值不在于给出唯一“正确答案”，而在于可追溯、可挑战的推理。对高影响事项，在情景分析之外按需运用：

- **关键假设检验**：列出结论隐含依赖的假设（政策连续性、执法强度、汇率与贸易环境、公司暴露数据等），逐项问“该假设不成立时结论如何变化”；对缺乏支撑的假设补证据或列入待确认项。
- **竞争解释**：对政策动因和未来走向给出至少两种有一定证据支持的解读，说明各自依据、弱点、判别指标和最早可观察时点；不默写只采纳最符合直觉的一种。
- **信号与噪音区分**：结构性信号（立法、预算、人事、执法记录、机构变化）重于偶发噪音（单次表态、个案、媒体热度）；单一事件只能证明该事件存在。
- **历史类比纪律**：类比只用于生成假设和提示验证方向；说明先例与当前在制度背景、技术条件和相互依存结构上的异同，不直接作为证据。

技术服务于判断：高影响事项必须体现，低影响事项不为篇幅机械罗列。

## 八、政策事项卡片

```markdown
### [政策或监管事项]

- **政策原文/官方口径**：[P-F]……[S1]
- **大白话**：……
- **政策动因**：官方目的……；分析推论……
- **竞争解释**（高影响或涉地缘政治、科技竞争事项选用）：……；判别指标……
- **政府层级与传导**：……
- **公司含义**：[A]……
- **受影响主体/业务**：……
- **资金与时间影响**：……
- **方向 / 程度 / 置信度**：……
- **成立条件**：……
- **关键例外**：……
- **失效点**：……
- **待确认项**：[Q]……
- **优先级**：P0 / P1 / P2 / P3
```

不必为低价值事项填满卡片；宁缺毋滥，只对与公司决策相关且证据足够的事项展开。
