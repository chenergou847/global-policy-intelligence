# 公司影响、总体方向与优先级

## 一、六维影响框架

多事项或复杂公司影响按需使用以下维度；单项直接影响不必逐节填表。

### 1. 主体

识别受影响的法人、分支、合资公司、持牌主体、申报主体、供应商或客户。核对所有权、规模、上市状态和许可证类型是否改变适用性。

### 2. 业务

分析产品准入、生产、销售、营销、定价、数据与技术、采购供应链、人力资源、政府客户以及市场进入/退出。

### 3. 资金

分析收入、成本、税费、现金流、补贴、政府采购、资本开支、融资、外汇、利润汇回、罚款和整改成本。

### 4. 时间

对齐政策公布、实施、过渡、申报和复审日期，以及公司预算、合同、产品和投资周期。

### 5. 角色

分别说明管理层要决定什么、公共事务要沟通什么、法务要确认什么、财务要测算什么、业务要改变什么、审计风控要留存什么。

### 6. 情景

执行或未来变化会影响重要决策时，选择基准、收紧、放宽/机会等相关情景，必要时增加地方执行差异；不强制三情景。

## 二、逐事项方向

- `-2` 重大利空：可能影响经营连续性、市场准入、牌照、核心收入或产生重大不可逆成本；
- `-1` 一般利空：增加成本、流程、时限或局部业务压力；
- `0` 中性/混合：有充分依据显示净影响有限、正负效果接近或主要为程序变化；
- `+1` 一般利好：降低局部成本、改善需求或提供可实现机会；
- `+2` 重大利好：显著扩大市场、降低核心成本或形成高确定性政策收益；
- **证据不足**：关键规则、公司适用性或暴露未确认，无法定向；不赋 `0`，不加入净方向计算。

同时记录影响程度（高/中/低）、发生概率（高/中/低）、公司暴露（高/中/低）和置信度（高/中/低）。

数据充分时，可用以下概念公式辅助排序：

`事项方向分 = 方向 × 影响强度 × 公司暴露 × 发生概率 × 时间权重`

不要把该公式包装成精确预测。缺少真实暴露或概率数据时，用分级矩阵，不计算小数。

## 三、总体方向

先完成逐事项评估，再给净判断：

- **利好**：正向影响显著占优，且有高/中置信度的公司传导路径；
- **利空**：准入、执法、成本或连续性压力显著占优；
- **中性偏利好**：正负并存，但可实现机会略占优；
- **中性偏利空**：正负并存，但风险或成本略占优；
- **中性**：证据充分且净影响有限、相抵或公司暴露很低；说明仍有何局部变化；
- **证据不足**：缺少定向所需的法规、公司暴露或传导依据；说明缺口与下一步，不强行判断利好或利空。

若不同业务的正负影响明显但缺少可比权重，可报告“证据不足以汇总集团净方向”，并保留已核验的分业务判断；不能假定正负抵消。关键未知本身也不自动构成利空。

总体判断按任务规模说明必要的依据和边界；多事项扫描重点包括：

1. 哪些业务和地域主导结果；
2. 公司暴露如何影响权重；
3. 结论成立条件；
4. 关键例外和反向信号；
5. 哪个政策或公司事实变化会使判断失效；
6. 仍需确认什么。

不要按政策数量投票，不把小市场的强政策自动上升为集团判断，也不把“政府支持行业”直接等同为公司受益。

## 四、P0–P3

优先级由紧迫性、不可逆性、法律/财务影响、政策窗口和依赖关系共同决定。只对真实风险、机会或核验动作分级，不强制为每个 P 级创建空章节；风险与机会分类不因某类为空而补材料。

| 级别 | 定义 | 典型事项 | 时限 |
|---|---|---|---|
| P0 立即行动 | 已发生或极可能很快造成违法、停业、牌照、重大资金损失，或不可逆窗口即将关闭 | 生效义务未满足、监管问询、许可到期、补贴窗口将关闭、证据需保全 | 0–7天，必要时当天 |
| P1 高优先级 | 一个月内需决策或启动，影响重大但仍有准备空间 | 新规即将生效、预算调整、准入方案、重大征求意见或政府沟通 | 30天内 |
| P2 计划推进 | 一个季度内应完成准备，影响中等或条件较多 | 流程改造、合同调整、地方试点、条件性机会 | 1–3个月 |
| P3 持续观察 | 政策早期、影响较低或证据不足 | 草案早期、政治表态、低暴露市场、未证实舆情 | 设置触发器和复查日 |

合规风险与政策机会分别排序。机会也可为 P0，例如申请窗口即将关闭。P0 必须写“为何不能等”；P3 必须写触发器，不以“持续关注”结束。

## 五、管理紧迫度

在 P0–P3 之外，为每项重点事项确定紧迫度分级，供报告“优先级与紧迫度矩阵”使用。优先级回答“资源竞争时按什么顺序投入”；紧迫度回答“管理层还有多少时间处理该事项”。两者相关但不互相替代：

| 分级 | 定义 | 常见对应 |
|---|---|---|
| 即时决策 | 决策窗口在一个季度以内，拖延将造成不可逆损失或错失窗口机会 | P0 / P1 |
| 窗口内准备 | 方向已明确、需在规划期（一至两个季度）内完成准备，或存在显著不确定性须纳入预算与规划 | P1 / P2 |
| 跟踪观察 | 当前可控、证据不足或偏机会；设置触发器并按期复查 | P2 / P3 |

紧迫度由决策窗口和不可逆性决定，不由事件热度或媒体关注度决定。低概率、高影响的尾部风险（如制裁列名、断供、市场准入突然关闭）紧迫度可以是“跟踪观察”，但必须配套触发指标、触发后预案和低成本对冲动作，不得以“概率低”了结。

证据不足不自动等于 P3 或“跟踪观察”；若潜在后果重大、截止日迫近，核验或专业确认动作可以是 P0/P1，但不得把待核风险写成已发生的事实。

## 六、行动闭环

每项行动至少包含：

| 字段 | 要求 |
|---|---|
| 动作 | 使用核查、测算、申报、沟通、整改、留存等具体动词 |
| 责任角色 | 管理层、区域公共事务、法务、财务、税务、业务、风控等，不虚构姓名 |
| 时限 | 绝对日期或明确的相对窗口 |
| 依赖 | 内部数据、专业意见、主管部门口径、预算或前置决策 |
| 验收标准 | 何种文件、决定、申报回执、整改证据或量化结果表示完成 |
| 对应事项 | 连接到政策、风险或机会编号 |

## 七、财务和法务参考价值

按事项与读者需要提供专业信息，不为不相关角色扩展章节。财务关注：收入/成本/现金流方向、税费或补贴条件、预算影响、测算缺口和会计/税务专业确认点。

法务关注：适用主体、义务与禁限、法律状态、生效和过渡期、处罚或牌照影响、合同/数据/治理动作及需当地律师确认的事项。

公共事务关注：主管部门、政策窗口、沟通目标、申报路线、地方裁量和需要验证的执行口径。
