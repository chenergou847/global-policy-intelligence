# 检索与存证工作流

批量扫描或网页读取受限时使用本参考。单项政策可用网页工具直接打开官方原文，不必先运行所有注册表适配器。

## 范围与覆盖

先列业务实际涉及的法域、主管机关、议题、回看窗口、关键存量规则和前瞻节点。注册表只提供有限站点适配器；当前配置偏保险/金融议题，默认仅美国与英国官方源。缺少适配器不等于该法域没有变化。逐项记录覆盖、命中、原文获取和未覆盖原因。

## 检索顺序

1. 用文件全称、文号、当地语言术语检索官方法规、公报或主管机关。记录检索日期与窗口。
2. 打开实际原文，核对标题、发布机关、发布日期、法律状态、生效日期、附件和修订版本。不得用搜索摘要代替正文。
3. 需要批量处理时进入技能 `tools/`：先 `doctor`，再 `collect --dry-run --sources <keys>`，确认覆盖与预算后采集到任务自己的证据目录。
4. 正文按已配置 API、纯文本、HTML、PDF、外部渲染器回落。仍不可读时记录状态、原因和尝试；缩小判断或提供待核验项。
5. 整理报告与逐项声明台账，运行严格校验，然后人工复核适用性、台账覆盖和推理。

```bash
python -m collector collect --sources federal_register --max-fetch 10 --evidence /path/to/project/evidence
python -m collector verify /path/to/report.md --claims /path/to/claims.json --evidence /path/to/project/evidence
```

显式 `--sources` 会选择停用适配器；未知 key 报错，停用源的历史 probe 不因此升级。`doctor` 只检查依赖与配置环境，不做线上可用性验证。`probe: verified` 表示历史测试状态，不能证明执行日仍可访问。

## 证据状态

| 获取状态 | 可用边界 |
|---|---|
| full | 完整性候选；核对正文边界与附件后才可支撑核心结论 |
| partial | 存在截断、混合扫描页或启发式边界；明确缺口，补全文前不能支撑核心结论 |
| listing_only | 仅线索，不能支撑政策条款事实 |
| scanned_pdf | 图像页无可用文字层；需 OCR/VLM 后复核，不能直接引用 |
| blocked | 未取得正文，说明限制与替代路径 |

权威等级另列：L1 原始权威、L2 官方解释、L3 专业补充、L4 一般线索、L5 未核实。核心事实与推论需 full L1/L2，不能只因字数足够或网页加载成功就提高置信度。

`cssselect` 处理 CSS 语法；无效选择器显式失败。HTML 启发式边界标 partial。`pypdf` 解析文字层；损坏文件标 failed，扫描件明确标记，不再使用正则猜测 PDF 字体编码。

## 网络与预算

HTTPX 按环境代理路由；`--direct` 忽略环境代理，`--no-direct-fallback` 禁止回落直连。保留 TLS 校验，反爬、验证码、登录墙不绕过。显式 `--insecure` 仅用于已接受该条件的诊断，相关证据须说明。

正文预算按条目计，不等于 HTTP 请求数；每个条目可能经历多个回落级和重试。配置页数、条目数、超时、同域间隔及响应大小应适合任务规模。列表为空或失败必须人工核对；不能推出“近期无政策”。

## 存证与审计

索引、正文快照、实际引用 URL、获取状态和时间一起保留。同 URL 内容变化保留历史；损坏索引拒绝覆盖。标题相同不证明同一版本。报告内的关键声明与引用通过 `claims.json` 逐项绑定，格式见 [claims-ledger.md](claims-ledger.md)。

严格模式核对引用索引、快照可读性与完整性、核心声明证据等级，以及事实数字和引文在指定快照中的命中。`company`、`assumption`、`inference` 需显式区分。报告截止日期、内部经营数字、行动截止日不能伪装成政策条文中的数据。

无台账的 `--legacy-checks-only` 仅运行旧全局匹配，不提供逐项验收。机器不能判断法条是否适用于公司，也不能证明因果、全面覆盖或无遗漏。交付前必须复核这些边界。
